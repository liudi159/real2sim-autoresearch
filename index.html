01 / THE RESEARCH LOOP

让误差，决定下一步实验。

研究的核心是解释偏差。每一轮选择一个可证伪的假设，再决定应该优化参数、修订模型，还是获得新的观测。

REASON → TEST → DECIDE

先解释误差，再决定改什么。

读取残差和失败记录，提出最多三个竞争解释。检索能够改变实验决策的证据，调用已验证技能，在冻结的开发协议下接受、拒绝或保留候选。

竞争假设实验预算保留 / 回滚
研究 Agent、优化器与 Coding Agent 如何分工？

研究 Agent

诊断残差、检索依据、选择技能和补测动作，决定本轮研究问题。

数值优化器

在给定边界、损失与预算中评估候选参数，返回拟合与敏感性信息。

Coding Agent

为缺失技能或模型机制编写候选补丁，通过局部检查与回归后才进入实验。

阶段 1 / 3定义可证伪解释

摩擦偏低，是否足以解释过长滑移？

先固定已校准的尺度、时间与初始状态。比较不同接触摩擦下的减速度形状，检查残差是否对该参数敏感。

需要的证据

同一接触表面上的完整滑动轨迹，以及可靠的初速度与时间戳。

候选修改有边界开发协议保持冻结失败实验保留
?

证据不足时，输出下一次该测什么。高度耦合的参数不应被强行变成一个“准确答案”。主动选择能放大竞争解释差异的动作，并把采集成本计入预算。

04 / A CONCRETE CASE

从捏下胶头，
到解释液面为什么上升。

胶头滴管把刚体、柔性形变、接触与流体连接在一起。研究从可观测过程拆解，而每一层都需要自己的证据。

01 / CONTACT

夹爪接触与压缩

对齐接触位置、夹爪运动、压缩位移与可选的力观测。先确定边界条件。

02 / DEFORMATION

胶头形变与回弹

比较弹性与黏弹性等竞争模型；用不同压缩深度和速度检查有效参数。

03 / TRANSFER

容积变化与吸液

连接气腔压力、密封状态、管路与流量。液面和吸液量需要独立测量。

如何设置一个可验证的起点？

先恢复结构

由视频和实测尺寸建立玻璃管、胶头与容器；保留开口及装配关系。

再分层辨识

先测胶头压缩与回弹，再校准压力—容积—流量模型。仅有视频时标记无法辨识的量。

最后检验迁移

冻结候选后，更换压缩深度、释放速度或浸入条件，评估未见交互中的预测。

案例范围：本页给出研究设计。流体与柔性耦合需要专用模型及验证，刚体场景重放本身不能证明吸液机制成立。

05 / EVIDENCE BEFORE CLAIMS

能运行、能预测、能辨识。
分开回答这三个问题。

拟合集用于优化，开发验证集用于模型选择。最终测试在候选冻结后独立执行，不向研究循环提供迭代反馈。

Sim-ready

场景可运行

检查单位与坐标、碰撞开口、支撑关系、稳定性和重放接口。

证据：场景检查与运行日志
LEVEL 02

Predictively aligned

行为有预测力

在未参与拟合的动作上，对比开放式多步运动、力或形变。

证据：独立真实交互
LEVEL 03

Physically identified

参数有辨识依据

检查敏感性、参数耦合与不确定性，注明假设及有效范围。

证据：测量与辨识诊断

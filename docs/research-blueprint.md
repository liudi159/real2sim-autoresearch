# Real2Sim AutoResearch

Di Liu · 2026-10-03 · 研究方案

目标：输入真实视频及可选的相机、机器人动作、深度与力观测，构建可编辑、可执行的仿真场景；让 Agent 根据真实与仿真的差异提出假设、调用技能、安排实验，并通过独立验证输出数字孪生及适用范围。

## 三个目标

- **Sim-ready**：场景能加载、稳定运行，单位、碰撞和支撑关系经过检查。
- **Predictively aligned**：在未参与拟合的真实动作上有预测能力。
- **Physically identified**：特定参数获得足够的测量、敏感性与可辨识证据。

三者分别验收。视觉相似和任务成功不能单独证明材料参数真实。

## 三种循环

1. 研究外循环：读取残差 → 提出最多三个竞争解释 → 检索与选择证据 → 调用技能与安排实验 → 依据冻结的开发验证协议接受、拒绝或保留候选。
2. 辨识内循环：在相同动作输入下运行仿真 → 对比轨迹、力或形变 → 有界优化参数 → 检查敏感性、参数耦合和不确定性。
3. 证据更新循环：选择可区分假设的补测动作 → 记录新数据与采集成本 → 更新证据记忆 → 在相同数据版本上重评候选与基线。

最终测试在候选冻结后独立进行，不把测试反馈送回研究循环继续挑选模型。

## 角色职责

- 研究 Agent：误差诊断、竞争假设、文献查询、技能选择与实验设计。
- 数值优化器：在明确的参数边界、目标函数和预算内进行候选评估。
- Coding Agent：实现缺失技能和有证据的模型修订；在独立候选中验证后接入流程。
- 评估器：冻结数据划分、评价指标、接受条件和最终测试入口。

## 资产与表示

用同一 object_id 连接视觉资产、碰撞资产、观测 mask 和仿真对象。几何单位、尺度、坐标和轴向明确。容器的开口和内腔在碰撞几何中保留；胶头等柔性部件根据形变证据选壳、体或经验证的近似模型。

参数记录区分 measured、identified、effective 和 assumed；保留证据、单位、适用接触对、后端字段与不确定性。有效拟合值不自动等于真实材料常数。

## 胶头滴管案例

1. 几何与接触：玻璃管、圆头胶头、容器和夹爪的结构与边界条件。
2. 压缩与回弹：用不同深度和速度的形变过程区分弹性、黏弹性等候选模型。
3. 压力与吸液：结合密封、气腔容积、管路与液面观测辨识有效流动模型。
4. 独立验证：冻结模型后测试未参与拟合的压缩、释放和浸入条件。

本页为研究设计，没有提供已验证的流体耦合求解器或实测性能。

## 最终数字孪生包

scene、collision_assets、physical_parameters、parameter_belief（如适用）、model_code、backend_lock、replay_actions、measurement_provenance、validation_report、applicability。
